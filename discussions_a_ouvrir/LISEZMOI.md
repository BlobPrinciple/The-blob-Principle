# Discussions à ouvrir

Chaque fichier `.md` de ce dossier (sauf celui-ci) ouvre une discussion GitHub lors de sa poussée sur `main`, grâce à l'action « Ouvrir les discussions » (`.github/workflows/ouvrir-discussions.yml`). Une discussion déjà ouverte sous le même titre n'est jamais recréée.

Format : ligne 1 « # Titre » ; ligne 2 facultative `<!-- categorie: General -->` ; puis le corps en Markdown.

*Each `.md` file here (except this one) opens a GitHub discussion when pushed to `main`. A discussion with the same title is never created twice.*
