# Code de conduite

Le laboratoire du Blob Principle est un lieu de travail scientifique ouvert à tous.

1. **Critiquer les idées, jamais les personnes.** La réfutation la plus sévère est bienvenue ; le mépris ne l'est pas.
2. **Argumenter avec des preuves.** Un calcul, un contre-exemple, une référence, une page précise.
3. **Honnêteté épistémique.** Ne pas présenter une analogie comme une identité, une mesure comme un théorème, une hypothèse comme un résultat.
4. **Respect des débutants.** Les questions du public sont légitimes ; on y répond avec patience.
5. **Attribution.** Citer ses sources et ne pas s'approprier le travail d'autrui.

Les messages contraires à ces règles peuvent être masqués, et leurs auteurs exclus du dépôt, à la discrétion de l'auteur du programme.
