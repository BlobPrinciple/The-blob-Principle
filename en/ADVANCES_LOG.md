# Advances log

This log records, in order, every **accepted** contribution: checked, re-run when it contains computation, and approved by the author. An advance can be a proof, a refutation, an independent replication or an error found in the corpus. A refutation has the same place here as a proof.

Contributions made with an AI, including the author's own, follow the same path: an issue using the “AI-assisted contribution” template, checking by the [pilot](AI_PILOT.md), then approval by the author ([GOVERNANCE.md](GOVERNANCE.md)).

Each entry updates the challenge history in [docs/defis.json](../docs/defis.json). An advance that changes a status is published in a new version of the repository, archived on Zenodo.
