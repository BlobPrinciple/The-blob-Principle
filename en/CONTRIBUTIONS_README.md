# Contributions

Place your contributions in the `contributions/` folder, in a subfolder named `RO-xx_your-name/` (or `critique_your-name/`, `replication_your-name/`).

Each subfolder contains at least a `RAPPORT.md` (report: statement, hypotheses, method, result, effect on the residue) and, for any measurement, the code, the seeds and the SHA-256 fingerprints of the outputs. See [CONTRIBUTING.md](CONTRIBUTING.md).
