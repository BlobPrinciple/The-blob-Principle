# Contributions

Déposez ici vos apports, dans un sous-dossier nommé `RO-xx_votre-nom/` (ou `critique_votre-nom/`, `replication_votre-nom/`).

Chaque sous-dossier contient au minimum un `RAPPORT.md` (énoncé, hypothèses, méthode, résultat, effet sur le résidu) et, pour toute mesure, le code, les graines et les empreintes SHA-256 des sorties. Voir [CONTRIBUTING.md](../CONTRIBUTING.md).
