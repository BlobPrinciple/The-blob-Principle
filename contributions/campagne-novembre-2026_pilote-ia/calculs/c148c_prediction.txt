1. BRANCHES
(N) Loi de NIVEAU. Les cellules prises dans la matiere ne se divisent pas, leur nombre M se conserve, les autres se divisent a cadence fixe k.
    Alors c = k (1 - M/N) et H(z)/H0 = [1 - m0 (1+z)^3] / (1 - m0), m0 = fraction bloquee aujourd'hui.
(F) Loi de FREIN, famille a un exposant n > 0 : dc/dt = - kappa c^(2-n) rho, rho = densite de matiere, conservee, diluee comme 1/N.
    Integration exacte : c^n = c_inf^n + n kappa rho, soit [H(z)/H0]^n = 1 - w + w (1+z)^3.
    n = 2 : frein independant de la cadence ; c'est exactement LambdaCDM plat, la constante cosmologique etant la constante d'integration
    (cadence libre c_inf), et kappa = 12 pi G. n = 1 : frein proportionnel a la cadence. n -> 0 : frein proportionnel a c^2 (H exponentiel en rho).
(B) Lois LOCALES qui donnent toutes la meme histoire d'ensemble (celle de n = 2) :
    dc/dt = B (c_inf^2 - c^2) - 12 pi G (1 - 2B) rho,   drho/dt = - c rho,   avec la condition de platitude c^2 = c_inf^2 + 24 pi G rho au depart.
    B = 0 : frein pur. B = 1/3 : equation de Raychaudhuri sans cisaillement (Newton + constante). B = 1/2 : aucun frein de la matiere.
    Hypothese [H] : la loi est locale, chaque region la suit avec sa propre densite.
(S) Lecture CINEMATIQUE (hypothese de travail, non attribuee a l'auteur) : la mitose arretee dans un corps est un simple deficit de volume cree ;
    le tissu alentour afflue a la vitesse v = c_inf V / (4 pi r^2), V = volume du corps.
