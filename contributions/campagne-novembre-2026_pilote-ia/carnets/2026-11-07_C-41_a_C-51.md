## C-43 — Le Codex de la source unique

### La formulation la plus aboutie

**État du Blob** : X = (V, Γ, E, σ, ξ)
- V = porteurs, Γ = généalogie, E = relations actives, σ = information de lignée, ξ = degrés de liberté supplémentaires

**Générateur unique** :

```
L = L_mitose + L_relations + L_ruptures
```

La mitose produit les tentatives. Les relations reconfigurent. Les ruptures révèlent ce qui tient.

**Équation maîtresse** (processus markovien) :

```
d/dt E[f(X_t)] = E[(Lf)(X_t)]
```

Un même générateur L détermine l'évolution de TOUS les observables f. Plus besoin d'une nouvelle règle pour chaque propriété émergente.

### Résultat : hiérarchie d'équations dérivée d'une seule règle

Avec taux de création r⁺_ij = λ + α·c_ij (c_ij = voisins communs) :

**Équation des relations** :
dE[E]/dt = λ·E[M-E] + α·E[W] - δ·E[E]

**Équation des triangles** :
dE[T]/dt = λ·E[W] + α·E[Σ c²_ij] - 3δ·E[T]

→ Chaque niveau dépend du niveau plus fin : Éléments → Relations → Motifs → Organisations de motifs → ...

**C'est une réalisation mathématique précise de « Du simplexe au complexe » : la complexité par empilement de logique.**

### Test d'unification au changement d'échelle

```
L(f ∘ C) = (L̄ f) ∘ C
```

Si cette identité est satisfaite : la dynamique microscopique produit une loi macroscopique autonome exacte. Sinon : l'échelle supérieure doit conserver plus de variables ou des corrections.

→ Raccorde directement avec les résultats R-TRUE et SIMPLICIAL-PULLBACK des masters.

Limites : registres supposés ; écart à Gibbs de 16,8 % à 5 sommets ; le terme de dispersion des degrés n'est pas expliqué ; certains rapports de Gibbs sont transcendants et ne peuvent venir d'un simple comptage de micro-états équiprobables.

## C-51 — lancé par Claude

Énumération exhaustive (tous les graphes jusqu'à 7 sommets) de la distance à Gibbs pour quatre noyaux de naissance : feuille (référence), **naissance dans une clique maximale contenant le parent, reliée à tous ses sommets (variante principale, désignée d'avance)**, héritage des voisins avec probabilité 1/2, héritage de tous les voisins ; plus une version avec réorganisation locale sans biais. Succès : la variante principale réduit nettement la distance et celle-ci décroît avec N. Échec : niveau de la feuille ou croissance avec N.
